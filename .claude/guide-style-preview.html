House Style Guide

A living demo of the visual system used across the interview preparation guides. Open this file in a browser to verify how the style looks; print to PDF to check that syntax colours and code backgrounds survive the conversion. The accent shown here is deep cyan. See section 4 to pick a different one.

1. Typography system

Body text is set in Newsreader, an editorial Old-Style serif that reads comfortably at length on both screen and paper. Headings use Fraunces, an optical-size serif with character. Code uses JetBrains Mono at every size.

Inline code shares the same monospace family, distinguished by a tinted background and a subtle border. Bold text is set slightly heavier and slightly darker for emphasis within a paragraph.

Sub-section heading (h3)

Sub-sections use h3, set in Fraunces at a smaller size. Use them to organise content within a major section. Do not go deeper than h3 in this system.

A short list to show list styling:

  • First item with some inline code in it.
  • Second item with a bold phrase mid-sentence.
  • Third item, plain text, normal weight.

2. Code blocks

Code blocks have a tinted background, a rounded border, and a three-pixel left rule in the accent colour. A small language badge appears in the top-right corner. In the built guides the highlighting is pre-rendered server-side; in this preview it is applied by highlight.js from CDN.

JavaScript

// Debounce: delay execution until activity stops
function debounce(fn, delay) {
  let timer
  return function (...args) {
    clearTimeout(timer)
    timer = setTimeout(() => fn.apply(this, args), delay)
  }
}

const search = debounce(query => fetch(`/api?q=${query}`), 300)

Vue SFC

<script setup>
import { ref, computed } from 'vue'
const query = ref('')
const items = ref(['apple', 'banana', 'cherry'])
const filtered = computed(() =>
  items.value.filter(i => i.includes(query.value))
)
</script>

<template>
  <input v-model="query" placeholder="Filter" />
  <ul><li v-for="item in filtered" :key="item">{{ item }}</li></ul>
</template>

5. Printing to PDF

Print from a modern browser (Chrome or Edge). The stylesheet sets print-color-adjust: exact, so syntax-highlighted backgrounds and token colours carry into the PDF without any extra settings. If colours still drop, enable Background graphics in the browser print dialog.

Long code lines wrap on paper (white-space: pre-wrap is applied in the print stylesheet) so nothing clips at the page edge. Tables and headings avoid awkward page breaks where possible. The page margin is 16mm on all sides.
